# Fasal

Field notes on the crops behind everyday life.

## Quick Start

You can run and build the project from this workspace directory or inside the `fasal` subdirectory:

```bash
# Option 1: Serve from workspace root
python3 -m http.server 8000
# Then open: http://localhost:8000/ (auto-redirects to fasal/index.html)

# Option 2: Build the static site generator
python3 fasal/tools/build.py

# Option 3: Double click
# Open fasal/index.html directly in any modern browser (file:// is fully supported)
```

For full documentation, architecture notes, and design tokens, see [fasal/README.md](file:///C:/Users/singh/Downloads/fasal/fasal/README.md).
